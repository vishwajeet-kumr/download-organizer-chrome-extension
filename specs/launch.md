# launch.md — Download Organizer Pro

## Post-Launch Growth Checklist

> Read this file AFTER Phase 5 is complete and the extension is live on the Chrome Web Store.
> These are not build tasks — they are distribution and growth actions.
> Execute them in order within the first 2 weeks of launch.

---

## Week 1 — Distribution Blitz

- [ ] **Reddit — r/productivity**
  Post title: "I built a Chrome extension that auto-sorts your downloads into folders — no more chaos"
  Include a before/after screenshot of the Downloads folder.
  Reply to every comment within 24 hours.

- [ ] **Reddit — r/chrome**
  Same post, slightly adjusted title for the audience:
  "Built a Chrome extension: every download goes to the right folder automatically"

- [ ] **Reddit — r/webdev**
  Angle: behind-the-scenes build post.
  "I built and published a Chrome extension in X days using MV3 — here's what I learned"
  Include what was hard, what MV3 gotchas hit you, link to the extension at the end.

- [ ] **Product Hunt launch**
  Submit at producthunt.com/posts/new
  Tagline: "Every download, in its place. Automatically."
  First comment: write a founder story — why you built it, who it's for, what's free vs Pro.
  Schedule launch for a Tuesday or Wednesday (highest traffic days).

- [ ] **Demo video — 60 seconds max**
  Screen record:
    1. Open cluttered Downloads folder (5 seconds)
    2. Show extension popup (5 seconds)
    3. Download a JPG, a PDF, an MP4 in sequence (20 seconds)
    4. Open Downloads folder — files are sorted (10 seconds)
    5. Show Pro upgrade screen (5 seconds)
  Post to Twitter/X, LinkedIn, and as a YouTube Short.
  No voiceover needed — add text captions.

## Week 2 — Directory Listings

- [ ] **alternativeto.net** — add as alternative to manual file sorting
  URL: alternativeto.net/browse/add

- [ ] **Chrome extension directories**
  Submit to: extensiondirectory.com, chrome-stats.com

- [ ] **Hacker News — Show HN**
  Title: "Show HN: Chrome extension that auto-sorts downloads by file type"
  Post on a weekday morning US time (highest visibility).
  Keep the comment short — let the product speak.

---

## Ongoing — Every Week

- [ ] **Respond to every Chrome Web Store review**
  Even one-star reviews. A founder who responds ranks higher and converts better.
  Target: respond within 48 hours of every new review.

- [ ] **Check Chrome Developer Dashboard every Monday**
  Track: weekly installs, active users, uninstalls, rating.
  If uninstall rate > 30% → investigate UX, not marketing.

- [ ] **A/B test Store listing after 30 days**
  Change the short description (132 chars) to a different angle.
  Wait 2 weeks. Compare install rate.
  Keep the version with higher conversion. Repeat.

## Revenue Targets

| Milestone | What it means |
| ----------- | -------------- |
| 100 installs | Extension is discoverable — keep going |
| 500 installs | Enough sample size to read reviews and improve |
| 5% Pro conversion | Healthy — $25–$50/month starting base |
| 1,000 installs | Strong organic growth signal — double down on Reddit |
| 10,000 installs | Scale paid keywords in Chrome Web Store listing |
